# Скриншоты MarketHub

Все кадры приложения сняты Playwright на синтетических fixtures выделенной тестовой PostgreSQL базы. Реальные магазины, credentials и пользовательские данные не использовались.

Страницы сняты целиком, модальные окна — в пределах viewport: это сохраняет фактическое положение фиксированных диалогов относительно экрана при прокрутке.

- `screenshots/` — восемь компактных кадров для основного README: landing, dashboard, каталог, товар, подключения, остатки, закупки и телефон.
- `visual/{1440,1280,1024,768,390,375}/` — полные страницы и состояния: вкладки подключения, физические/внешние остатки, склады/движения, поставщики, закупки/приёмки, формы, mapping, confirmation, галерея, tours и навигация.
- `visual/geometry.json` — измерения header/sidebar/font в браузере.
- `reference/` — shadcn-admin на 1440, 1280, 1024, 768 и 390 px; source MIT notice находится в `../licenses/`. На 375 px Netlify показал проверку соединения, поэтому этот кадр исключён из эталонов.
- `comparison/` — парные контактные листы Dashboard и таблиц reference/MarketHub. Состав данных различается; листы служат для проверки геометрии и визуального языка, не для сравнения текста или расчёта процента совпадения пикселей.

Из `frontend/` запустите `npm run test:e2e -- --config=playwright.visual.config.ts`, затем `node scripts/compare-reference.mjs`. Нужны Chrome, PHP, vendor и отдельная `markethub_api_test` БД, настроенная в `.env.testing`. Не запускайте одновременно с backend suite. Снимки reference собраны с живого сайта, не перегенерируются локальным тестом.
