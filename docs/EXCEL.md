# Экспорт Excel

- `GET /api/v1/products/export` — только локальные SKU, без самостоятельных внешних Shopify/WB/Ozon вариантов.
- `GET /api/v1/stocks/export` — остатки размещений.

Оба маршрута требуют Sanctum, действующего членства в организации и разрешения Policy `viewAny`. Используются текущий OrganizationContext и глобальная область Eloquent. Пользователь без организации получает 403. Параметр organization_id не переключает организацию.

Поддерживаются фильтры и сортировка соответствующих списков API. `page` и `per_page` не ограничивают выгрузку: экспортируются все подходящие записи. Поиск и сортировка определены в общем CatalogQuery. FromQuery читает записи частями с уникальным ID как дополнительным ключом сортировки; связи остатков загружаются заранее.

Файл содержит русские заголовки, закреплённую строку заголовков и автофильтр. Цены представлены числами в основных денежных единицах с двумя знаками и отдельной валютой; даты — числовыми значениями Excel с форматом даты и времени. Все строки записываются с TYPE_STRING: формулы не исполняются, ведущие нули SKU сохраняются. Нулевые остатки сохраняются числами.

Кнопка «Экспорт локальных SKU» в общем каталоге выгружает все локальные товары текущей организации **без фильтров списка**; эта область явно подписана рядом с кнопкой. Фильтры общего каталога по внешним полям не выдаются за фильтры local export. Кнопка экспорта остатков передаёт параметры своего списка. Используется авторизованный Axios-клиент с cookies. Ответ скачивается как Blob; ошибки отображаются, повторное нажатие блокируется на время запроса. Demo-пользователю доступен экспорт для просмотра; лимит — 10 запросов в минуту на user+IP.

Установлен maatwebsite/excel 4.0.6: его composer.json разрешает PHP ^8.3 и illuminate/support ^12.0 || ^13.0, что совместимо с Laravel 13 проекта. Используется PhpSpreadsheet 5.11.0. Для установки и работы необходимо расширение GD; на текущей машине включён уже установленный php_gd.dll в C:/tools/php83/php.ini. При переносе окружения включите GD перед composer install. Заказов в проекте нет, их экспорт не добавлялся.

Проверено: полный backend-набор — 36 тестов, 241 проверка; отдельно ExportTest с размером части 1 — 4 теста, 57 проверок. Тесты читают реальные XLSX, проверяют содержимое, форматы, формулы как текст, нулевые остатки, фильтры, сортировку, игнорирование пагинации, изоляцию организаций, 401/403/422. Использован временный PostgreSQL 17 на порту 55432 с отдельной базой markethub_api_test и локалью ru-RU, поскольку основная служба была выключена и недоступна для запуска без административных прав. Временный сервер после проверки остановлен.
